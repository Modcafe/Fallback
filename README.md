Fallback delivers a lot of usefull features for Datapack developers, such as Configuration screens using a simple API or advanced Math. Fallback is still in early Work in Progress, and not all features are existing yet or working properly, but we'll expand this Library over time to make it more accessible to other people.

## Features

<details>
<summary>APIs</summary>

<details>
<summary>LoggerAPI</summary>

A modern logger for in-game chat logging using the DateAPI.

`/fallback log info|success|error|warn <AUTHOR> <MESSAGE>`

</details>
<details>
<summary>DateAPI</summary>

Provides the local date(time) in different formats.
</details>

</details>


- LoggerAPI to log Problems
- DateAPI to provide the Date in different Formats
- RandomDialogAPI to show random dialogs to players, but never repeat them
- (W.I.P.) Math API

<small><i>W.I.P. = Work in Progress, T.B.R. = To be removed</i></small>
